# Nirvana Mart — Website E-Commerce Tugas

Website ini dibuat berdasarkan persyaratan pada file Tugas E-Commerce Manajemen:
- Home
- Profil bisnis
- Katalog produk
- Detail produk
- Harga
- Informasi kontak
- Cara pemesanan
- Promo/diskon/bundling
- Target pasar
- Kategori produk
- Pembayaran dan pengiriman
- Navigasi yang jelas
- Keranjang dan demo checkout

## Teknologi
HTML5, CSS3, JavaScript vanilla.

## Cara menjalankan
1. Ekstrak folder.
2. Buka `index.html` di Google Chrome/Edge.
3. Tidak membutuhkan server atau instalasi tambahan.

## Catatan
Nama bisnis, nomor WhatsApp, email, produk, harga, dan lokasi adalah data contoh yang dapat diganti sesuai kelompok.
